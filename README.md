# UniRouter - نظام إدارة أجهزة الأبراج والراوترات

تطبيق مبني باستخدام **Flutter & Dart** لإدارة ومراقبة أجهزة الأبراج والراوترات (MikroTik, Ubiquiti, OLT) واكتشاف حالة الاتصال آلياً.

## المميزات الأساسية:
- فحص حالة الأجهزة (Online / Offline) عبر بروتوكول Ping.
- دعم أجهزة الميكروتك، أجهزة البث والربط اللاسلكي، وأجهزة الفايبر.
- تصميم حديث ومتوافق مع مختلف الشاشات.
